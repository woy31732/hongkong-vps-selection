## 买香港VPS之前，先搞懂这几个容易混淆的概念

很多人第一次买香港VPS，最容易被"三网直连"和"住宅IP"这两个词绕进去，觉得看起来都挺高端，但其实针对的是完全不同的需求。

**三网直连线路**说的是国内到香港机房的网络路径。常见的说法有CN2、CN2 GIA、CUII、CMI这几种，简单理解就是电信、联通、移动各自选择比较优质的骨干网线路直连香港，减少绕路和拥堵，白话说就是"国内访问香港服务器不卡"。以丽萨主机的三网直连产品为例，去程走的是电信CN2、联通CUII、移动CMIN2，回程强制走CMI，第三方测评显示晚高峰时段这类线路依然能跑满标称带宽，说明直连确实起到了作用。这类线路更适合看重国内访问速度的场景，比如建站、远程办公、内部系统访问。

**住宅IP（Residential IP）**则是另一个维度的概念，跟线路快不快没直接关系，核心是IP地址的"身份"。普通机房IP（Datacenter IP）容易被流媒体平台、广告投放系统、社交媒体风控识别为服务器IP，进而触发限制或者直接拒绝访问；住宅IP则挂在本地ISP的家庭宽带段下面，在这些平台眼里更像是一台普通家用电脑或者手机在访问，因此在解锁Netflix、Disney+、TVB、Cityline之类的港区流媒体，或者做TikTok运营、社媒广告投放时命中率会明显更高。丽萨主机的iCable和HGC两条产品线走的就是这个路子,用的是香港本地宽带运营商的原生住宅IP段。

所以选购逻辑很简单：如果你主要图国内访问快、用来建站或搭建应用,优先看直连线路的带宽和延迟；如果你要做流媒体解锁、跨境电商店铺、TikTok账号运营,住宅IP的纯净度往往比带宽数字更重要。
